# Splitly

เว็บแอปหารค่าใช้จ่ายทริปและกลุ่มกับเพื่อน แต่ละคนมีบัญชีของตัวเอง และเข้ากลุ่มได้ด้วยการสแกน QR เชิญของคนสร้างกลุ่ม

เว็บจริง: https://splitly-q3cbw.netlify.app

## วิธีใช้งาน

1. สมัครบัญชีด้วย **ชื่อผู้ใช้ + รหัสผ่าน** (ชื่อผู้ใช้ห้ามซ้ำกับคนอื่น) แล้วกรอกโปรไฟล์: ชื่อเล่น พร้อมเพย์ และเลขบัญชี
2. คนสร้างกลุ่ม: กด **สร้างกลุ่มใหม่** แอปจะแสดง **QR เชิญ** ให้
3. เพื่อน: สแกน QR ด้วยกล้องมือถือ หรือกด **สแกนเข้ากลุ่ม** ในแอป ถ้ายังไม่ได้ล็อกอิน แอปจะให้ล็อกอินหรือสมัครก่อน แล้วพาเข้ากลุ่มต่อให้เอง
4. ล็อกอินบัญชีเดียวกันที่เครื่องไหนก็เห็นกลุ่มของตัวเองครบ ข้อมูลในกลุ่มซิงก์ถึงกันทุก 5 วินาที

## Deploy ขึ้น Netlify

ต้องมี Node.js 18 ขึ้นไป และบัญชี Netlify

```bash
npm install
npm install -g netlify-cli
netlify login
netlify init        # สร้างเว็บใหม่บน Netlify (ครั้งแรกครั้งเดียว)
netlify deploy --prod
```

ข้อมูลบัญชีและกลุ่มเก็บไว้ใน **Netlify Blobs** ของเว็บนี้ ไม่ต้องสมัครฐานข้อมูลอื่นเพิ่ม

ถ้าต้องการ ตั้ง `SPLITLY_SECRET` ใน Netlify (Site configuration > Environment variables) เป็นข้อความสุ่มยาว ๆ ได้ ใช้เซ็นรหัสล็อกอิน ถ้าไม่ตั้ง ระบบจะสร้างให้เองแล้วเก็บไว้ใน Blobs

> การลากโฟลเดอร์ไปวางในหน้า Netlify (drag and drop) จะไม่ deploy ส่วน API ให้ ต้องใช้ `netlify deploy` หรือเชื่อมกับ Git

## ทดสอบในเครื่อง

```bash
npm test                     # ทดสอบ API: สมัคร ล็อกอิน กลุ่ม สิทธิ์
node test/local-server.mjs   # เปิดแอปที่ http://localhost:8787 (ข้อมูลหายเมื่อปิด)
netlify dev                  # หรือรันแบบ Netlify จริงที่ http://localhost:8888
```

ถ้าจะสแกน QR ด้วยกล้องจากมือถือจริง ต้องเปิดผ่าน https (หลัง deploy แล้ว) เพราะเบราว์เซอร์ไม่ให้ใช้กล้องบน http

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html`, `public/app.js`, `public/style.css` | ตัวแอป |
| `netlify/functions/api.mjs` | API: บัญชี (`/api/auth`, `/api/me`) และกลุ่ม (`/api/groups`) |
| `netlify/lib/auth.mjs` | hash รหัสผ่าน, session cookie, ตรวจชื่อผู้ใช้และโปรไฟล์ |
| `netlify/lib/groups.mjs` | กฎการบันทึกข้อมูลกลุ่มและสิทธิ์สมาชิก |
| `test/` | ชุดทดสอบ และเซิร์ฟเวอร์ทดลองในเครื่อง |
| `prototype/index.html` | ต้นแบบแรก (ไฟล์เดียว ไม่มีระบบบัญชี) เก็บไว้ดูเป็นตัวอย่าง |

## บัญชีและความปลอดภัย

- รหัสผ่านเก็บแบบ hash (scrypt) ไม่เก็บรหัสจริง ล็อกอินค้างไว้ด้วย cookie แบบ HttpOnly 60 วัน
- ใส่รหัสผิด 8 ครั้ง ชื่อผู้ใช้นั้นจะถูกล็อก 10 นาที
- เปลี่ยนรหัสผ่านแล้ว เครื่องอื่นที่ล็อกอินอยู่จะถูกออกจากระบบ
- เห็นและแก้ข้อมูลกลุ่มได้เฉพาะสมาชิก แก้หรือลบโปรไฟล์ของเพื่อนที่มีบัญชีไม่ได้ (แก้ได้เฉพาะเพื่อนที่ถูกเพิ่มชื่อไว้โดยยังไม่มีบัญชี)
- ใครมี QR หรือลิงก์เชิญจะเข้ากลุ่มได้ ส่งให้เฉพาะคนในกลุ่ม
- **ยังไม่มีระบบลืมรหัสผ่าน** เพราะยังไม่ได้ใช้อีเมล ถ้าลืมต้องสมัครบัญชีใหม่
