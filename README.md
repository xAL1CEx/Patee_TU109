# Splitly

เว็บแอปหารค่าใช้จ่ายทริปและกลุ่มกับเพื่อน แต่ละคนมีบัญชีของตัวเอง เข้ากลุ่มด้วย QR เชิญ โอนเงินคืนผ่าน QR พร้อมเพย์ และมีตัวช่วยหาร้านอาหารให้กลุ่ม

เว็บจริง: https://splitly-q3cbw.netlify.app

## ทำอะไรได้

- **บัญชี:** สมัครด้วยชื่อผู้ใช้ + รหัสผ่าน (ชื่อผู้ใช้ห้ามซ้ำ) ใส่ชื่อเล่น และเลือกช่องทางรับเงิน **อย่างใดอย่างหนึ่ง** คือพร้อมเพย์หรือบัญชีธนาคาร (บังคับกรอกให้ครบตามที่เลือก)
- **กลุ่ม:** ทริป กลุ่ม หรือกิจกรรม เลือกวันเริ่ม–วันสุดท้ายจากปฏิทิน แบ่งกิจกรรมย่อยได้ เพิ่มเพื่อนที่ยังไม่มีบัญชีไว้ก่อนแล้วให้เขารับชื่อทีหลัง เชิญด้วย QR / ลิงก์ / LINE
- **ค่าใช้จ่าย:** หารเท่ากัน หรือกำหนดเองเป็นบาทหรือเปอร์เซ็นต์ คนที่จ่ายเป็นคนบันทึก และแก้หรือลบได้เฉพาะคนบันทึก
- **ยอดเงิน:** ยอดระหว่างเรากับเพื่อนแต่ละคน กดชื่อเพื่อดูประวัติว่ายอดมาจากรายการไหน และสรุปรายจ่ายรายหมวด รายกิจกรรม รายคน
- **จ่ายเงิน:** QR พร้อมเพย์ตามมาตรฐาน Thai QR พร้อมยอด (บันทึกรูปไปสแกนในแอปธนาคารได้) หรือคัดลอกเลขบัญชี ยอดตั้งแต่ ฿2,000 แบ่งจ่าย 2–3 งวดรายเดือนได้ การโอนนับเมื่อผู้รับกดยืนยัน ทวงได้ทางแอป LINE หรือคัดลอกข้อความ
- **ไปกินที่ไหนดี:** ค้นร้านอาหารรอบสถานที่ที่เลือก (ปุ่มลัด พิมพ์ชื่อ หรือตำแหน่งปัจจุบัน) รัศมี 1–10 กม. เรียงตามจำนวนคน กรองประเภท (กาแฟ เกาหลี ก๋วยเตี๋ยว ฯลฯ) และเปิด Google Maps / โทร / เว็บร้านได้ ใช้ได้เฉพาะในประเทศไทย
- **ธีมสี:** 8 ธีม แต่ละเครื่องเลือกเอง

## วิธีใช้งานเบื้องต้น

1. สมัครบัญชี ใส่ชื่อเล่น และเลือกรับเงินผ่านพร้อมเพย์หรือบัญชีธนาคาร
2. กด **สร้างกลุ่มใหม่** แล้วกด **เชิญเพื่อน** เพื่อแสดง QR
3. เพื่อนสแกน QR ด้วยกล้องมือถือ (หรือกด **สแกนเข้ากลุ่ม** ในแอป) ถ้ายังไม่ได้ล็อกอินจะให้ล็อกอินหรือสมัครก่อน แล้วพาเข้ากลุ่มต่อให้เอง
4. คนที่จ่ายเงินไปก่อนกด **เพิ่มค่าใช้จ่าย** เลือกคนที่หาร
5. ดู **ยอดระหว่างคุณกับเพื่อน** ที่หน้าแรก ถ้าเราค้างเพื่อน กด **จ่าย** แล้วสแกน QR พร้อมเพย์ จากนั้นกด **ฉันโอนแล้ว** คนรับกด **ได้รับแล้ว** ยอดถึงจะหัก
6. อยากรู้ว่าไปกินที่ไหน กด **ไปกินที่ไหนดี?** เลือกสถานที่ ปรับรัศมี และกรองประเภทร้าน

ล็อกอินบัญชีเดียวกันที่เครื่องไหนก็เห็นกลุ่มของตัวเองครบ ข้อมูลในกลุ่มซิงก์ถึงกันทุก 5 วินาที

## Deploy ขึ้น Netlify

ต้องมี Node.js 18 ขึ้นไป และบัญชี Netlify

```bash
npm install
npm install -g netlify-cli
netlify login
netlify init        # สร้างเว็บใหม่บน Netlify (ครั้งแรกครั้งเดียว)
netlify deploy --prod
```

ข้อมูลบัญชีและกลุ่มเก็บไว้ใน **Netlify Blobs** ของเว็บนี้ ไม่ต้องสมัครฐานข้อมูลอื่นเพิ่ม

> การลากโฟลเดอร์ไปวางในหน้า Netlify (drag and drop) จะไม่ deploy ส่วน API ให้ ต้องใช้ `netlify deploy` หรือเชื่อมกับ Git

### ค่าที่ตั้งได้ (ไม่ตั้งก็ใช้งานได้)

ตั้งที่ Netlify: Project configuration > Environment variables แล้ว **deploy ใหม่หนึ่งครั้ง** ค่าถึงจะมีผล

| ตัวแปร | ใช้ทำอะไร | ถ้าไม่ตั้ง |
|---|---|---|
| `SPLITLY_SECRET` | ข้อความสุ่มยาว ๆ ใช้เซ็นรหัสล็อกอิน | ระบบสร้างให้เองแล้วเก็บไว้ใน Blobs |
| `FOURSQUARE_API_KEY` | รวมร้านจาก Foursquare (ใช้เฉพาะช่องที่ฟรี) ให้ค้นร้านได้มากขึ้น | ค้นร้านจาก OpenStreetMap อย่างเดียว |

เก็บกุญแจไว้ฝั่งเซิร์ฟเวอร์เท่านั้น ติ๊ก **Contains secret values** ตอนสร้างตัวแปร ห้ามใส่ในไฟล์โค้ดหรือขึ้น GitHub

## ทดสอบในเครื่อง

```bash
npm test                     # ชุดทดสอบ 32 ข้อ ไม่ต้องต่ออินเทอร์เน็ต
node test/local-server.mjs   # เปิดแอปที่ http://localhost:8787 (ข้อมูลหายเมื่อปิด)
netlify dev                  # หรือรันแบบ Netlify จริงที่ http://localhost:8888
```

- ถ้าอยากลองรวมร้านจาก Foursquare ในเครื่อง สร้างไฟล์ `.env` ที่โฟลเดอร์หลัก ใส่บรรทัด `FOURSQUARE_API_KEY=ค่าของคุณ` (ไฟล์นี้ถูกตั้งให้ Git ข้ามอยู่แล้ว และต้อง Node.js 20.12 ขึ้นไปถึงจะอ่านไฟล์ได้)
- ถ้าจะสแกน QR ด้วยกล้องหรือใช้ตำแหน่งปัจจุบันจากมือถือจริง ต้องเปิดผ่าน https (หลัง deploy แล้ว) เพราะเบราว์เซอร์ไม่ให้ใช้กล้องและตำแหน่งบน http
- ลองสองบัญชีพร้อมกันบนเครื่องเดียว: เปิด `http://localhost:8787` กับ `http://127.0.0.1:8787` สองแท็บ (คุกกี้ล็อกอินแยกกัน)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html`, `public/app.js`, `public/style.css` | ตัวแอป (HTML, CSS, JavaScript ล้วน) |
| `netlify/functions/api.mjs` | API: บัญชี (`/api/auth`, `/api/me`) กลุ่ม (`/api/groups`) ค้นร้าน (`/api/places`) ค้นชื่อสถานที่ (`/api/geocode`) |
| `netlify/lib/auth.mjs` | hash รหัสผ่าน, session cookie, ตรวจชื่อผู้ใช้และโปรไฟล์ |
| `netlify/lib/groups.mjs` | กฎการบันทึกข้อมูลกลุ่ม ค่าใช้จ่าย การโอน และสิทธิ์สมาชิก |
| `netlify/lib/places.mjs` | ค้นร้านอาหารจาก OpenStreetMap และ Foursquare รวมผล แคช และจำกัดจำนวนครั้ง |
| `test/` | ชุดทดสอบ และเซิร์ฟเวอร์ทดลองในเครื่อง |
| `prototype/index.html` | ต้นแบบแรก (ไฟล์เดียว ไม่มีระบบบัญชี) เก็บไว้ดูเป็นตัวอย่าง |

## กฎและความปลอดภัย

กฎเรื่องเงินถูกบังคับที่ฝั่งเซิร์ฟเวอร์ทั้งหมด ไม่ใช่แค่ซ่อนปุ่มในหน้าเว็บ

- รหัสผ่านเก็บแบบ hash (scrypt) ไม่เก็บรหัสจริง ล็อกอินค้างไว้ด้วย cookie แบบ HttpOnly 60 วัน
- ใส่รหัสผิด 8 ครั้ง ชื่อผู้ใช้นั้นจะถูกล็อก 10 นาที
- เปลี่ยนรหัสผ่านแล้ว เครื่องอื่นที่ล็อกอินอยู่จะถูกออกจากระบบ
- เห็นและแก้ข้อมูลกลุ่มได้เฉพาะสมาชิก แก้หรือลบโปรไฟล์ของเพื่อนที่มีบัญชีไม่ได้ (แก้ได้เฉพาะเพื่อนที่ถูกเพิ่มชื่อไว้โดยยังไม่มีบัญชี)
- ใครมี QR หรือลิงก์เชิญจะเข้ากลุ่มได้ ส่งให้เฉพาะคนในกลุ่ม
- คนที่จ่ายเงินต้องเป็นคนบันทึกรายการเอง (ยกเว้นเพื่อนที่ยังไม่มีบัญชี) และแก้หรือลบได้เฉพาะคนบันทึก เซิร์ฟเวอร์ตรวจด้วยว่ายอดเป็นบวกและยอดที่แบ่งรวมกันเท่ายอดเต็ม
- การโอนนับเมื่อผู้รับกดยืนยัน ผู้โอนยืนยันให้ตัวเองไม่ได้
- ออกจากกลุ่มไม่ได้ถ้ายังค้างเงินคนอื่น ลบกลุ่มได้เฉพาะคนสร้างและเมื่อไม่มีใครค้างใคร
- ค้นร้านได้คนละ 40 ครั้งต่อ 10 นาที ผลค้นเก็บแคชไว้ 30 นาที

## ข้อจำกัดตอนนี้

- **ยังไม่มีระบบลืมรหัสผ่าน** เพราะยังไม่ได้ใช้อีเมล ถ้าลืมต้องสมัครบัญชีใหม่ และยังไม่มีปุ่มลบบัญชี
- ปุ่ม "ฉันโอนแล้ว" ไม่ได้เช็กกับธนาคาร คนรับต้องกดยืนยันเอง
- แจ้งเตือนเห็นตอนเปิดแอปเท่านั้น ไม่มีแจ้งเตือนเด้งบนมือถือ
- ร้านอาหาร: ข้อมูลมาจากแหล่งเปิด ครอบคลุมไม่ครบทุกร้าน ไม่มีคะแนนรีวิวและรูปร้านจริง (การ์ดใช้ภาพอาหารตามประเภท) ไม่รู้จำนวนที่นั่ง และรัศมีกว้างในเมืองใหญ่ได้แค่ตัวอย่างบางส่วน
- ร้านจากแหล่งฟรีอาจตอบช้าบางครั้ง ถ้าช้าให้กด "ข้อมูลยังไม่ครบ ค้นอีกครั้ง"
